SPM 99

A matlab program for interfacing with SPM 99 has been written. The user can control the same parameters as in the coregistration part of SPM, and once the Go! button is pressed, a new matlab process is spawned, in which SPM is running in batch mode.
Figure 6: Interface to the coregistration methods of SPM 99
For information on the SPM coregistration methods, refer to the SPM 99 documentation.
