Example data

Example data to load into the programs are available in the directory ../data. The data are
  • MR_sub1.* - T1 weighted MRI dataset in Analyze format.
  • PET_sub1.* - F-18 Altanserin PET T1 dataset in Analyze format.
  • Sub1.mat - Point definition file for use with IPS.
  • IIO.air - Output registration parameters from IIO.
  • IPS.air - Output registration parameters from IPS.
Note: The .air files usually written using MARS have reslice and standard filenames defined with full path. This is not the case with the example airfiles. To avoid problems interpreting these airfiles, cd to the ../data folder before starting MARS.
