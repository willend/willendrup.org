System and Data Requirements

The software package has been developed for the workstation specified in PVEOut, an x86 machine running Linux with a standard GNU development environment and Matlab.

Some of the visualisation features of the Matlab part of the coregistration package require that the installed matlab version is 6.x

The image data format supported by the programs is Analyze format (both 'ieee-le' and 'ieee-be'). Many conversion programs are available on the internet for conversion to this format.
