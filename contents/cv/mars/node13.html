Startup

On startup of the IPS registration module, four windows appear.
  • A main control window.
  • A point list window
  • A 3-pane viewer for the standard dataset
  • A 3-pane viewer for the reslice dataset
The two former windows are depicted in Figure 7, and the two latter in Figure 8.
Figure 7: Main control window and point list of IPS
Figure 8: 3-pane windows for standard and reslice images.
If transformation parameters have previously been defined in the main MARS interface, the user is offered to use these for 'Coarse Prealignment' of the reslice dataset.
