Air 5.0

A reasonably user friendly tcl interface is included in the Air 5.0 for easy access to the adjustable parameters of the method. In the PVEOut coregistration package, a similar interface exists:
Figure 5: Matlab interface to Air 5.0 alignment
Only a few features are different from those of align.tcl:
  • The standard / reslice thresholds can be specified as a percentile fraction of the difference between the actual minimum and maximum values of the different datasets.
  • A button for visual inspection without reslicing datasets is available, relying of the common inspection module defined within the main MARS interfaece.
Apart from these features, refer to the Air 5.0 documentation for usage information.
